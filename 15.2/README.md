### Задание 1. Yandex Cloud 

**Что нужно сделать**

1. Создать пустую VPC. Выбрать зону.
2. Публичная подсеть.

 - Создать в VPC subnet с названием public, сетью 192.168.10.0/24.
 - Создать в этой подсети NAT-инстанс, присвоив ему адрес 192.168.10.254. В качестве image_id использовать fd80mrhj8fl2oe87o4e1.
 - Создать в этой публичной подсети виртуалку с публичным IP, подключиться к ней и убедиться, что есть доступ к интернету.
3. Приватная подсеть.
 - Создать в VPC subnet с названием private, сетью 192.168.20.0/24.
 - Создать route table. Добавить статический маршрут, направляющий весь исходящий трафик private сети в NAT-инстанс.
 - Создать в этой приватной подсети виртуалку с внутренним IP, подключиться к ней через виртуалку, созданную ранее, и убедиться, что есть доступ к интернету.

# Отчёт по заданию 1 - Yandex Cloud

---

## Подготовка

Задание опирается на инфраструктуру из ДЗ 15.1. Работа выполнена через Terraform.
Используется провайдер `yandex-cloud/yandex`, переменные вынесены в `variables.tf`, значения секретов — в `terraform.tfvars` (в git не коммитятся).

Файлы конфигурации:

- `providers.tf` — настройка провайдера Yandex Cloud.
- `variables.tf` — переменные (`cloud_id`, `folder_id`, `zone`, ключи SA, имя бакета).
- `main.tf` — VPC, подсеть `public`, бакет, объект, Instance Group, сетевой балансировщик.
- `cloud-init.yaml` — стартовая веб-страница ВМ.

---

## Пункт 1. Бакет Object Storage с картинкой

- Создан сервисный аккаунт с ролью `storage.editor`, получены статические ключи, вынесены в `terraform.tfvars`.
- Создан бакет `geolook-20261007`.
- Публичный доступ настроен отдельным ресурсом `yandex_storage_bucket_grant.images_public` с grant `READ` для группы `AllUsers`.
- В бакет загружен файл `picture.png` через `yandex_storage_object.picture`.

## Пункт 2. Группа ВМ в public-подсети с LAMP и веб-страницей

- Создана Instance Group `lamp-group` из 3 ВМ фиксированного размера.
- Образ LAMP: `image_id = fd827b91d99psvq5fjit`.
- ВМ размещены в подсети `public`, имеют публичный IP (`nat = true`).
- Через `user_data` (файл `cloud-init.yaml`) создаётся стартовая страница `/var/www/html/index.html`:
```
<html> <head><title>HW 15.2</title></head> <body> <h1>Группа ВМ 15.2 работает</h1> <img src="https://storage.yandexcloud.net/geolook-20261007/picture.png" width="400"> </body> </html>
```

## Пункт 3. Подключение группы к сетевому балансировщику
- Создан сетевой балансировщик net-lb с listener на порту 80.
- К балансировщику подключена целевая группа lamp-tg, созданная Instance Group.
- Health check балансировщика: порт 80, путь /.
- Тест отказоустойчивости: одна ВМ была удалена из группы, группа автоматически восстановила количество инстансов, балансировщик продолжил отдавать страницу.
